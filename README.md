# ♟️ Basic Chess Game

A simple browser-based chess game built using **HTML, CSS, and JavaScript**.

This project is a beginner-friendly web application that allows two players to play a basic chess game directly in a web browser.

## 🚀 Features

* ♟️ 8×8 chessboard
* ♔ White and Black chess pieces
* 👥 Two-player gameplay
* 🔄 Turn-based gameplay
* 🖱️ Click to select and move pieces
* 🎯 Basic chess piece movement
* ❌ Capture opponent pieces
* 🔄 Reset Game button
* 📱 Responsive design
* 🌐 Runs directly in a web browser

## 🛠️ Technologies Used

* **HTML5** – Creates the structure of the chess game
* **CSS3** – Designs and styles the chessboard
* **JavaScript** – Handles game logic, turns, and piece movement

## ▶️ How to Run

No Python, Django, or other software is required.

### 1. Download or clone the repository

```bash
git clone https://github.com/mrunalibadwaik2805-glitch/chess-game.git
```

### 2. Open the project

```bash
cd chess-game
```

### 3. Run the game

Open the `index.html` file in **Google Chrome** or another web browser.

You can also right-click `index.html` and select:

**Open with → Google Chrome**

## 🎮 How to Play

1. White starts the game.
2. Click on a chess piece to select it.
3. Click on another square to move the piece.
4. Players take turns between White and Black.
5. Opponent pieces can be captured.
6. Click **Reset Game** to restart the game.

## ⚠️ Limitations

This is a **basic chess game** created for learning purposes.

It does not currently include all official chess rules, such as:

* Check
* Checkmate
* Castling
* En passant
* Pawn promotion
* Complete legal move validation
* Chess AI
